# Rep Count

A mobile-first, beginner-friendly workout coach for a four-day muscle-gain program with climbing, recovery, progression, and practical dining-hall food guidance.

The workout player uses large tap controls for weight, reps, and RIR. Suggested weights begin as conservative trials, then use saved or restored workout history to repeat, increase, or reduce the load.

Rest timers are automatic: 2:30 for demanding compound exercises and 1:30 for isolation exercises. Exercise transitions use the longer recovery requirement of the two exercises.

## Run locally

Open `index.html` directly or serve the folder with any static server. The app has no build step and stores workout data locally in the browser.

Use **Back up** on the Workouts page or workout summary to save a JSON copy through the iPhone share sheet (including Files/iCloud Drive) or a browser download. Use **Restore** to validate and import that file on another browser or device.

## GitHub Pages

Deploy the repository root as a static GitHub Pages site. All assets use relative paths, so project-site URLs work without additional configuration.
