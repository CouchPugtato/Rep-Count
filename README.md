# Rep Count - Workout Companion

A clean, mobile-friendly workout tracker website designed to run on GitHub Pages.

## Features
- **Mobile Responsive**: Looks great on your phone.
- **Workout List**: Easy to see your full routine.
- **Active Mode**: Focus on one exercise at a time.
- **Video Demonstrations**: Built-in video player for form checks.
- **Set Counter**: Track your progress through each exercise.

## How to Edit Your Workout
Open `workouts.js` and modify the `workoutRoutine` array.
You can change names, sets, reps, and paste your own YouTube embed links.

## How to Deploy to GitHub Pages
1. Upload these files to a GitHub repository.
2. Go to your repository **Settings**.
3. Click on **Pages** in the left sidebar.
4. Under **Build and deployment**, select `main` (or `master`) branch as the Source.
5. Click **Save**.
6. Your website will be live at `https://<your-username>.github.io/<repo-name>/` in a few minutes.
